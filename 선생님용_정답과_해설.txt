=====================================================
 가지를 찾아서: 독도 바닷길 대모험 - 선생님용 정답과 해설
=====================================================
 대상: 중학생 / 제한 시간 45분 / 힌트 전체 3회
 흐름: 교실 → 한반도(넓은 지도) → 배 → 울릉도 → 전망대 → 추격(1696) → 배 → 독도

■ 화면 안내
  · 찾아가야 할 곳 위에 노란 화살표 이름표가 통통 튀어요. (퍼즐을 풀면 사라짐)
  · 화면 위쪽 [전체 화면] 버튼: 브라우저 주소창까지 숨기기 / 다시 누르면 창 모드
    (타이틀을 누르는 순간에도 자동으로 전체 화면. 아이폰은 브라우저가 지원하지 않아 버튼이 숨겨져요)

■ 이야기
  수행평가 전날 교실에 남은 주인공. 사물함에서 독도에 살던 강치의 기억 '가지'가 나타난다.
  흩어진 독도의 기록 다섯 조각을 모으면 강치들의 바다가 돌아온다.
  (가지는 사물함을 연 뒤부터 주인공을 따라다니고, 배를 타면 잠시 숨는다)

-----------------------------------------------------
1. 교실
-----------------------------------------------------
 p1 하늘이 사물함 (자물쇠 3자리)  정답: 874
    단서: 짝꿍 쪽지 "독도에서 가장 가까운 '우리 섬'까지의 거리, 점은 빼고"
          + 게시판 포스터 (울릉도 87.4km / 오키섬 157.5km)
 p2 교실 문 이름 자물쇠 (다이얼)  정답: 우산 → 가지 → 석도
    단서: 낡은 해도(석도·우산·가지) + 교과서(우산 1454, 가지도 1794, 석도 1900, 독도 1906)
    학습: 독도의 옛 이름 / '가지도'는 강치(가지어)가 많아서 붙은 이름

-----------------------------------------------------
2. 한반도와 동해 (화면이 주인공을 따라가는 넓은 지도)
-----------------------------------------------------
 p3 한양 춘추관 (선택)  정답: ① 바라볼 수 있다      → 기록 조각 ② 세종실록지리지(1454)
    학습: "우산과 무릉 두 섬은 서로 거리가 멀지 않아 날씨가 맑으면 바라볼 수 있다"
 p4 강릉 이사부 비석 (선택)  정답: ② 사자            → 기록 조각 ① 삼국사기(512)
    학습: 지증왕 13년(512) 이사부가 나무 사자로 우산국을 항복시킴
 p5 동래 배 창고 (자물쇠 4자리)  정답: 1693
    단서: 기록판 "숙종 19년" + "숙종 원년 = 1675년" → 1675 + 18 = 1693
    학습: 1693년 안용복이 울릉도에서 일본 어부들과 마주침
 · 동래 부두에서 배를 타고(바다만 다닐 수 있음) 북동쪽 울릉도에 배를 대면 내린다.
 · 경주·울진·백두산·평양 표지판은 둘러보기용 (울진: '울진현 정동쪽 바다에 우산·무릉')

-----------------------------------------------------
3. 울릉도
-----------------------------------------------------
 p6 독도박물관 진열장 (자물쇠 4자리, 박물관 정문 앞)  정답: 1900     → 기록 조각 ③ 칙령 제41호(1900)
    단서: 칙령 날짜 "광무 4년 10월 25일" + 오른쪽 잔디밭 파란 안내판 '1900 칙령' ("광무 원년 = 1897년")
    · 파란 안내판에는 1900년 칙령 제41호 해설판(1897 대한제국 → 1900 울도군 → 1905 일본 발표 → 10월 25일 독도의 날)도 함께 나옴
    · 갈색 안내판 '일본 기록': 1877 태정관 지령, 1905 시마네현 편입 발표
    학습: 1900년 대한제국 칙령 제41호(울도군, 석도 관할) / 10월 25일 독도의 날
          1877년 태정관 지령, 1905년 일본의 시마네현 편입 발표(칙령보다 5년 뒤)
 p7 독도전망대 망원경 (다이얼)  정답: 동남 / 87.4km
    단서: 전망대 안내판 화살표(오른쪽 아래)와 나침반, 거리 87.4km
    → 성공하면 안개가 걷히고 수평선 위에 독도가 보인다
 p8 안용복의 기억 (추격)  북쪽 해안 '안용복 기념비'를 조사      → 기록 조각 ④ 안용복
    1696년, 안용복의 배가 되어 일본 어선 3척을 90초 안에 따라잡기
    (실패하면 처음부터 다시 도전, 바위 사이로 몰면 쉽다)
    학습: 안용복이 일본 어부들을 꾸짖고 자산도(독도)까지 쫓아감, 일본 호키주에 가서 따짐
          / 1696년 일본 에도 막부의 울릉도 도해 금지

 ※ 독도로 가려면 p7과 p8이 모두 필요 (도동항 → 배 → 동남쪽 독도)

-----------------------------------------------------
4. 독도
-----------------------------------------------------
 p9 독도경비대원 (다이얼)  정답: 동도 이사부 / 서도 안용복   → 기록 조각 ⑤ 오늘의 독도
    학습: 동도 '독도이사부길', 서도 '독도안용복길' (경상북도 울릉군 울릉읍)
 · 동도 선착장에서 서도로 건너가 계단을 올라 북서쪽 가제바위 석판으로
   (계단 중간 왼쪽 동굴 = 물골: 바위틈에서 맑은 물이 솟는 곳, 둘러보기용)
 · 서도 주민 숙소: 김성도(2018년 별세)·김신열(2020년 태풍 뒤 육지로, 2026년 3월 별세) 부부가 살던 곳.
   2026년 현재 독도에 사는 주민은 없음(주민등록 0명). 울릉군은 2027년 상반기 새 주민 모집을 추진 중.
 p10 기억의 석판 (다이얼 5칸)  정답: 512 / 1454 / 1696 / 1900 / 울릉군
    (삼국사기 / 세종실록지리지 / 안용복 / 칙령 제41호 / 오늘의 독도: 경상북도 울릉군)
    → 강치 9마리가 불꽃과 함께 하나씩 돌아오고 엔딩 → 정리 카드 → 후기 링크
